# VetConnect (proyecto académico — Codificación y Pruebas del Software)

```bash
cd backend
pip install -r requirements.txt
python app.py        # http://127.0.0.1:5000
pytest               # pruebas + cobertura (reporte HTML en backend/htmlcov)
```
Estructura: `frontend/` (HTML/CSS/JS), `backend/` (Flask + SQLite + pytest), `.github/workflows/ci.yml` (CI), `docs/registro_fallos.md`.

Documentación detallada de qué se hizo, en qué archivo y en qué línea: `docs/MAPA_DEL_PROYECTO.md`.
